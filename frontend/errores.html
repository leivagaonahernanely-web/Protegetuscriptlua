Errores del loader

Si el script no carga, el juego muestra uno de estos mensajes. Busca el código y sigue lo que dice.

KEY_REQUIRED

Falta la key

El script necesita una key y no la recibió.

Qué hacer: pega tu key en la variable script_key justo encima del loader.

KEY_INVALID

Key no válida

La key no existe para este script. Puede estar mal copiada o ser de otro script.

Qué hacer: copia la key de nuevo. Si sigue fallando, pide una nueva al creador.

KEY_EXPIRED

Key vencida

Tu acceso terminó.

Qué hacer: pide al creador una key renovada.

HWID_MISMATCH

Key vinculada a otro equipo

La key ya está vinculada a otro dispositivo.

Qué hacer: usa el equipo original, o pide al creador que reinicie el vínculo.

BLACKLISTED

Acceso denegado

La key, tu equipo, tu IP o tu cuenta de Discord están bloqueados para este script.

Qué hacer: escribe al creador si crees que es un error.

SCRIPT_NOT_FOUND

Script no encontrado

El loader apunta a un script que ya no existe o cambió de identificador.

Qué hacer: pide al creador el loader actualizado.

MAINTENANCE

Script en mantenimiento

El creador pausó este script por un momento.

Qué hacer: espera unos minutos y vuelve a intentar.

MAINTENANCE_ALL

Vantarmor en mantenimiento total

La plataforma está pausada completa: loaders, web y bot.

Qué hacer: espera a que termine. No hace falta cambiar nada.

SERVER_UNREACHABLE

No se pudo conectar al servidor

El ejecutor no llegó al servidor de verificación.

Qué hacer: revisa tu internet y vuelve a ejecutar. Si pasa siempre, prueba otro ejecutor.

CONNECTION_FAILED

Falló la descarga del script

La verificación salió bien, pero no se pudo descargar el código.

Qué hacer: vuelve a ejecutar. El intento es de un solo uso, así que no sirve reutilizar el anterior.

VERIFY_FAILED

Verificación fallida

El servidor no pudo confirmar tu acceso. Suele ser un problema temporal o un HWID que el ejecutor no entregó.

Qué hacer: vuelve a ejecutar. Si pasa siempre, cambia de ejecutor y avisa al creador.

PAYLOAD_LOAD_FAILED

El ejecutor no pudo cargar el código

La verificación pasó, pero el código protegido no se pudo cargar en tu ejecutor.

Qué hacer: avisa al creador: es un problema de la versión del script, no de tu key.

TAMPERING

Se detectó manipulación

El loader encontró algo que altera su funcionamiento normal (como hooks en el ejecutor o funciones modificadas).

Qué hacer: cierra los programas que modifiquen el ejecutor y vuelve a intentar. Si pasa siempre, usa un ejecutor sin modificaciones.

¿Tu error no está aquí? Escribe en soporte con el mensaje exacto que viste.
