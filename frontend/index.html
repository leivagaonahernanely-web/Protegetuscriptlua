Cómo funciona

De 0 a protegido
en menos de 2 minutos

Sin configuración complicada. Solo sube tu script, genera keys y empieza a proteger.

01

Sube tu script

Arrastra tu archivo .lua al panel o conéctalo vía API. Vantarmor lo ofusca automáticamente.

02

Genera keys

Crea tantas keys como necesites con duración personalizable. Desde el panel o con /genkey en Discord.

Distribuye

Comparte las keys con tus usuarios. Ellos las meten en el loader y se vinculan a su HWID al instante.

Monitorea

Observa en tiempo real quién usa tu script, detecta abusos y revoca acceso con un click.

Preguntas frecuentes

¿Qué es Vantarmor?

Un sistema para proteger scripts de Lua y Luau con keys vinculadas a HWID y control de acceso desde el panel web y el bot de Discord.

¿Tengo que cambiar el loader al actualizar el script?

No. Subir una nueva versión reemplaza el código actual y el loader sigue siendo el mismo.

¿Cómo funcionan las keys?

Cada key puede vincularse a un equipo (HWID) y tener fecha de expiración. Tú decides cuántas generar y a quién entregarlas.

¿Qué pasa durante un mantenimiento?

El mantenimiento normal pausa compras, canjes y scripts nuevos, y la web muestra un aviso. Si el mantenimiento es total, también se pausan los loaders y el bot.

¿Cada cuánto se renuevan los límites de los planes?

El plan Free se reinicia cada 15 días. Premium y Premium Plus se renuevan cada mes.

¿Necesito Discord para usarlo?

El panel web sirve para todo. El bot de Discord sirve para que tus usuarios reclamen keys y consulten su acceso.
