Keys y HWID

Mi key dice que es inválida

Revisa que copies la key completa, sin espacios al inicio o al final, y que sea para el script correcto. Si la key es de un plan, confirma que el plan no haya vencido en la sección Planes del panel.

¿Qué es el HWID y por qué mi key quedó vinculada?

El HWID identifica el equipo. La primera vez que se usa una key, queda vinculada a ese equipo para evitar que se comparta.

Cambié de equipo y ya no funciona

Puedes reiniciar el HWID con el botón Reset HWID del panel, en el script correspondiente. Solo se puede cada cierto tiempo, según la configuración del creador. Si el botón está deshabilitado, abre un ticket en Discord.

Me avisaron que compartí una key

Las keys son personales e intransferibles. Si se detecta uso desde otro equipo, la primera vez recibes un aviso, la segunda una advertencia más fuerte, y a la tercera la key se elimina y el acceso se bloquea en ese script.

Si crees que es un error, abre un ticket explicando la situación.

Loader y errores

Al ejecutar aparece "script no encontrado"

La URL del loader puede estar incompleta o el script fue eliminado. Copia el loader otra vez desde la página del script en el panel, sin modificar la URL.

El script carga pero no hace nada

Confirma que la key esté activa (no vencida ni bloqueada) y que el ejecutor tenga soporte para loadstring y HttpGet. Si el problema sigue, abre un ticket con el nombre del script y la hora del intento.

Veo una pantalla de mantenimiento

Estamos haciendo cambios en la plataforma. Durante el mantenimiento no se pueden comprar ni canjear keys, pero los scripts que ya tienes siguen funcionando. Vuelve en unos minutos o revisa Discord para ver las novedades.

Planes

¿Cómo canjeo una key de plan?

Entra al panel, abre Planes y pega la key en el campo de canje. Al canjearla, tu plan se activa de inmediato.

¿Cuánto dura un plan?

Cada plan dura 30 días desde el canje. Te avisamos antes de que venza para que puedas renovarlo sin perder tus scripts.

¿Qué incluye Premium Plus?

Premium Plus incluye todas las funciones de Premium, más el Ofuscador 3 y el mensaje de bienvenida en tu servidor de Discord. Los detalles completos están en la sección de planes del inicio.

Macros de rendimiento (Ofuscador 3)

¿Qué hacen las macros?

Las macros marcan funciones de tu script para que corran fuera de la máquina virtual del Ofuscador 3. Esas funciones se ejecutan más rápido, pero quedan menos protegidas.

¿Cuándo conviene usarlas?

En funciones grandes que se ejecutan muchas veces, como bucles o cálculos que corren cada frame, donde el rendimiento importa. Para lógica sensible, como validaciones, mejor déjalas protegidas.

¿Cómo las aplico paso a paso?

1. Al crear o editar un script, elige Ofuscador 3. Aparece el botón Macros de rendimiento (Ofuscador 3).

2. Pulsa el botón. El panel busca las funciones de tu código y te las muestra con su número de línea y cuántas líneas tienen.

3. Marca las funciones que quieras. Las de 30 líneas o más vienen marcadas por defecto; puedes cambiarlo.

4. Pulsa Aplicar al código. Se agrega LUO_NO_VIRTUALIZE() justo encima de cada función marcada.

5. Guarda el script para aplicar los cambios.

LUO_NO_VIRTUALIZE()
local function calcularRuta(puntos)
  -- tu código
end
Marqué una función por error. ¿Cómo la quito?

Abre el script en el editor, borra la línea LUO_NO_VIRTUALIZE() que está encima de esa función y guarda. Al guardar, la función vuelve a quedar protegida por la VM.

No aparece el botón de macros

El botón solo aparece cuando eliges Ofuscador 3. Ese ofuscador es exclusivo del plan Premium Plus. También puedes usarlo hasta 2 veces al día; cada guardado con Ofuscador 3 cuenta como una compilación.
