Preguntas que sí importan.

    

      

        ¿Mi código original queda expuesto?
        
No se entrega tal cual. Se guarda ofuscado y comprimido en el servidor, y solo se envía cuando la key es válida y el dispositivo coincide. Tu comprador recibe la versión protegida, que su executor necesita para ejecutarla. Ninguna ofuscación es imposible de revertir; por eso Premium usa un motor mucho más fuerte.

      

      

        ¿Funciona con cualquier executor?
        
El loader usa game:HttpGet y loadstring, que soporta la mayoría de executors. Prueba el tuyo primero con Key Trial antes de vender.

      

      

        ¿Qué pasa si borro un script o una key?
        
Se borran, pero tu cupo no se recupera. Los límites cuentan todo lo que has creado, para que nadie pueda crear y borrar sin fin en el plan gratis.

      

      

        ¿Cómo pago un plan?
        
Compras una key de plan al dueño y la canjeas en la página Plans de tu cuenta. El plan se activa al instante y se acumula si renuevas antes de que venza.

      

      

        ¿Y si se filtra la API key de mi script?
        
La regeneras desde la web. La key vieja deja de funcionar y el servidor de Discord vinculado se desconecta. Una API key solo se puede vincular a un servidor.
